# `playful-web-animations` Agent Skill

A motion-design and implementation skill for creating purposeful, polished web animation. It supports requested animations, UI construction that accounts for motion from the start, and restrained animation audits of existing projects.

## Use Cases

- Add tangible feedback and spatial continuity to interactions.
- Build informative animations with accessible non-animated equivalents.
- Direct attention without persistent or competing motion.
- Add tasteful moments of delight and brand personality.
- Review an existing interface and implement a coherent batch of high-value motion opportunities.
- Verify interruption behavior, reduced motion, accessibility, and rendering performance.

The skill is framework-aware rather than framework-specific: it favors platform features and the project's existing animation stack before adding dependencies.

## Real-World Example

[Add purposeful dashboard motion](https://github.com/kilinkis/adk-ikea-brand-analysis/pull/1) applied this skill to an existing React interface. The change introduced a small shared motion vocabulary for selection and confirmation feedback, removed an unjustified perpetual pulse, respected reduced-motion preferences, and added no dependencies.
